Adding Contents

  1. Click the Add Contents button.

  1. In the Search window, locate and select available dashboard reports.

  2. If a text field appears:

    1. Enter your search criteria and click the Search icon.

    2. Choose a report by clicking the radio button next to it or modify your criteria and search again.

  3. Choose where you want the report to appear on the dashboard. For example, selecting Add to the Top will place the report above all existing content.
