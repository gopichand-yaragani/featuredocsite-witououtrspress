About Discovery Scan

This module contains the following functions:

Dashboard contains a list of all the recent scans and any reports that have been added to the window. In this window, new content can be added and customized.
Run a Scan identifies the devices connected to and communicating in a network and allows for the configuration of a scan frequency.
Recent Scans displays successfully completed scans and creates a new scan to run.
Scheduled Scans enables the execution of scan functionality according to a configured date and time.
IPAM Networks enables the planning, tracking, and managing the information associated with an Internet Protocol address existing in the monitored network environment.
Discovered Items displays the details for a successful scan.
Import from AWS identifies information in Amazon Web Services (AWS).
Import from AZURE identifies information in AZURE, a cloud service owned by Microsoft.
Import Data Files imports details of CI, CI relations, and asset details from an Excel spreadsheet.
Imported Assets displays the results of data imported during the data files import operation.
AD User Import Logs displays scanned results and the details for imported AD users.
Azure AD User Import Logs displays scanned results and the details for imported Azure AD user.
LDAP User Import Scans displays scanned results and the details for imported LDAP Users.
