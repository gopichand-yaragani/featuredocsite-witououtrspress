Prerequisites for Scan

Credentials are required to scan the Target Host and can be entered using the methods described below.

  Added and imported credentials are encrypted and stored on the machine where the Discovery Application is installed.

Method 1: Through Virima Discovery Admin

Refer to Credentials.

Method 2: Through the Discovery Application using the Application Interface

1. Right-click the Virima Discovery Application.
2. Click Run as Administrator.
3. Click Start and wait until it shows that the Discovery Agent is Running.
4. From the Credentials drop-down list, select Add Credential.
The Add new credential window displays.
5. Complete the fields.
6. When all selections/entries are made, click Save.

Method 3: Load the Credentials from an Excel File

To load the credentials through this method, credentials must be configured in an Excel file, as shown in the figure below.

1. Store the credential file in this location: 
C:\Program Files\Virima Discovery Application\Config as Credentials.xls or Credentials.xlsx
2. Right-click the Virima Discovery Application.
3. Click Run as administrator.
4. Click Start and wait for the indication that the Discovery agent is Running.
5. In the Discovery Agent window, click the Credentials drop-down list and select Import Credentials.
  The added/imported credentials are encrypted and stored on the machine where the Discovery Application is installed.
