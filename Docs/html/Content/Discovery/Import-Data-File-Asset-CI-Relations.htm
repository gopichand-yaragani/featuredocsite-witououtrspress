Import Asset/CI Relations File

Use this function to upload and attach an asset/CI relations file

1. In the navigation pane, select Discovery Scan > Import Data Files. The Import Data Files window displays.
2. In the Select Actions drop-down list, choose Import Asset/CI Relations. The Attach Asset/CI Relations File dialog box displays.
3. To view a sample file, select Click here to download the sample file.
4. In the Upload Data field, click Browse and select an allowed file type (.xls, .xlsx and .cvs).
5. Click Upload.
