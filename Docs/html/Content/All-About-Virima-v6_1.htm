About the Virima Modules and Functions

The All Modules window contains quick access to selected functions. From this main window, all functions are reached either through:

The Navigation pane (down the left side of the window)
The Admin menu (in the upper right corner of the window)

Home Page/All Modules Window

The home page provides quick access to the most frequently used modules, such as favorite functions and dashboards.

Adding a Favorite. Locate an icon in the applicable section. Then, click and drag/drop the icon into the Favorite section inside the box with the text, "Drag here to add."
Deleting a Favorite. Locate the icon in the Favorites section. Then, click and drag the icon above the Favorite section until the text "Drag here to delete" inside a red box displays.

Left Navigation Pane

The left navigation pane includes the following:

My Dashboard displays data content information with a customization option.
CMDB provides a centralized repository for Configuration Items (CIs) and their relationships, with detailed CI profiles (attributes, ownership, linked components, dependencies, audit history, and lifecycle).
Discovery Scan manages scanning activities (running, scheduling, etc.) and importing data (such as from AWS and Azure).
ITAM (asset management functions) and ITSM (service management functions)
 

The menu heading displayed - either ITAM or ITSM - is based upon the subscription.

Vulnerability Management identifies, evaluates, and reports security vulnerabilities in CIs present inside the CMDB.
Self Service creates catalog items and shows incidents and requests for the current user.
Project and Program Management defines project aspects and managing related projects.
Risk Register provides a tool for managing risk and compliance.
Reports generates both canned and custom ad hoc reports.
MSP displays a list of clients and includes a Dashboard, Reports, My Incidents, and Administrative functions (Client, Users, Mailbox Monitoring Configuration, and Email Templates). It also provides access to the Virima application.

Admin Window

The administrative functions include the following:

Organizational Details specifies business-related details, such as departments, cost centers, locations, designations, operational hours, and holidays.
Discovery configures clients, defines credentials and major software, manages processes, and other discovery-related functionality (scan configuration, monitoring profile, and application mapping).
SACM handles blueprints, relationship types, confidence configuration, and software-related functions.
Users creates users, roles, groups, and time tracking reports. Also allows for AD import and authentication, Azure AD and SAML configuration.
Management Functions for Changes, Contracts, Events, Hardware Assets, Incidents, Knowledge, Problems, Projects, Releases, and Requests.
Integrations provides credential and mapping information for Cherwell, Ivanti, ServiceNow, and Jira Credentials and Infoblox configuration.
Others includes functions such as Announcements, KPIs, Business Rules, Role Access, and SMTP configuration.
