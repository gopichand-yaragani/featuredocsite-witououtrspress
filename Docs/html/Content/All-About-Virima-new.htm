Left Navigation Pane

The left navigation pane includes the following:

My Dashboard displays data content information with a customization option.
Discovery Scan manages scanning activities (running, scheduling, etc.) and importing data (such as from AWS and Azure).
ITAM/ITSM enables functionality for configurable items (such as components) and establishes audit activities.
 

The menu heading displayed - either ITAM or ITSM - is based upon the subscription.

ITAM displays when CMDB and other modules (such as hardware assets and contract and vendor management) are enabled.
ITSM displays when CMDB, Incidents/Changes/Problems and other ITSM modules are enabled.
Vulnerability Management identifies, evaluates, and reports security vulnerabilities in CIs present inside CMDB.
Reports generates both canned and custom ad hoc reports.

Admin Window

The administrative functions include the following:

Organizational Details specifies business-related details such as departments, cost centers, locations, designations, operational hours, and holidays.
Discovery configures clients, defines credentials, defines major software, manages processes, and other discovery-related functionality (scan configuration, monitoring profile, and application mapping).
SACM handles blueprints, relationship types, confidence configuration, and software-related functions.
Users creates users, roles, groups, time tracking reports and allows for AD import/authentication, and Azure AD and SAML configuration.
Incident Management defines escalations, categories, error codes, the incident model, priority calculator, states/sub states, and timescale.
