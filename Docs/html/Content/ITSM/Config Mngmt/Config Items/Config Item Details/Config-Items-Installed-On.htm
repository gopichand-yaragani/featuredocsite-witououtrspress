CI: Installed On

Use this function to view what software is installed on what system.

1. In the navigation pane, select ITSM > Configuration Management > CMDB. The Configuration Items window displays.
2. Select a record in the list. A new window opens and the Details tab displays.
3. Click the Installed On tab. A list of all settings on which the software is installed displays.
4. To view the details for an asset, click on the asset name. You are returned to the Configuration Items window.
5. To view the location for a selected asset, click View Map.
Edit Installed On
  Not all functions include an option to edit record line items shown in the main window.
1. Navigate to the window containing the record to edit.
2. Click the line containing the record. The applicable window or dialog box displays.
3. Make the necessary modifications.
4. Click Save or Add, as applicable.

When editing an existing item, other options may be available, such as adding Tasks, Comments, and Attachments and viewing History.

  The options change based upon the function; therefore, not every option may be shown.
Delete Installed On

To delete an existing record, select the record in the list. Then, from the Select Actions drop-down list, choose Delete.
