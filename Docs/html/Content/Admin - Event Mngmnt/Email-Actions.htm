Email Actions

Use this function to configure what action to take upon receipt of an email to create an ITSM record.

In the main window, click Admin > Event Management > Email Actions.

New Email Action
1. From the Select Actions drop-down list, choose New Action.
2. Complete the sections as described below.
3. When all selections/entries are made, click Add.

General Info

1. Enter a Name and Description for the email action.
2. Select Enable to define the corresponding email action as functional.
3. Select the Priority.
4. For Mailbox Configuration, click Add.
5. Search for and select the template to associate with this action. Then click Save.
6. Select to Turn on Cascade Execution.

Condition Details

1. Select Ignore Condition to ignore this condition for this email action.
2. In the Property and Operator fields, click the drop-down list and select the property and operator.
3. Enter the applicable value.
4. To configure an AND condition, click the green plus + sign icon.
5. To configure an OR condition, click the green | bar icon.
6. To remove an existing condition, click the red X icon.

Action Details

1. Select Ignore Action to ignore this action for this email action.
2. In the Target Module field, click the drop-down list and select the required module.
3. In the Create From Module field click the drop-down list, and select the appropriate model of the selected module.
4. In the Property field, click the drop-down list and select the property.
5. Select the applicable Value or Map. Choose the option based on the requirement, then enter/select the relevant value.
 

The values options to define “Set Value”, and “Map” depends on the type of selected Property. The values configured in the Email Template are also displayed.
6. To add another property, click the plus + sign.
7. To remove an existing property, click the minus + sign.
Edit Email Action
  Not all functions include an option to edit record line items shown in the main window.
1. Navigate to the window containing the record to edit.
2. Click the line containing the record. The applicable window or dialog box displays.
3. Make the necessary modifications.
4. Click Save or Add, as applicable.
Delete Email Action
  Deleting is a permanent action and cannot be undone. Deleting may affect other functionality and information in the application such as data in configured reports, fields in windows, selectable options, etc. Therefore, be sure to understand the potential effects before making a deletion.
1. Click the line that contains the item to delete.
2. From the Select Actions drop-down list, choose Delete. If a confirmation message is displayed, type Delete and click Deleteto confirm.
