Edit Blueprints

Use this function to edit the details for a blueprint.

1. In the Blueprints window, select a record to edit. The applicable record displays.
2. Modify any of the following information:
Details
SLA
Tasks
Comments
Attachments
3. When all selections/entries are made, click Save.
