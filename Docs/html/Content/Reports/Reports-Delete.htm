Delete Report

Use this function to delete a report from the applicable entities (for example, My Dashboard) and archive the report.

  Deleting is a permanent action and cannot be undone. Deleting may affect other functionality and information in the application such as data in configured reports, fields in windows, selectable options, etc. Therefore, be sure to understand the potential effects before making a deletion.
1. From the navigation pane, select either Reports > Ad Hoc Reports or Reports > Canned Reports. The Reports window displays.
2. In the list, select one or more reports to delete.
3. From the Select Actions drop-down list, choose Delete.
4. In the Confirmation Message window, Type Delete and click Delete.
  For System Administrators. Refer to Admin > Other > Reports to also perform this function.
