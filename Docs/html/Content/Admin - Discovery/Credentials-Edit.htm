Edit or Delete Credentials

Use this function to edit or delete the configured values for an existing credential.

Edit a Credential

1. In the main window, select Admin > Discovery > Credentials. The Credentials window displays.
2. In the main window, click the gear icon and select Discovery > Credentials. The Credentials window displays.
3. Select a record to edit. A new window displays with the Details tab selected.
4. Modify any of the following information:
Details
Tasks
Comments
Attachments
5. When all selections/entries are made, click Save.

Delete a Credential

  Deleting is a permanent action and cannot be undone. Deleting may affect other functionality and information in the application such as data in configured reports, fields in windows, selectable options, etc. Therefore, be sure to understand the potential effects before making a deletion.
1. Click the line that contains the item to delete.
2. From the Select Actions drop-down list, choose Delete. If a confirmation message is displayed, type Delete and click Deleteto confirm.
