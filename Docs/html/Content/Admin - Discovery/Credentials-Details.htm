Credential Details

Use this function to edit details for credentials.

  Not all fields are enabled to accept changes as the fields vary based on the Credential Type configured.
1. In the main window, click Admin > Discovery > Credentials. The Credential window displays.
2. Select an existing record. A new window displays with the Details tab selected.
3. Make the necessary modifications.
4. Modify the tabs according to the following:
Components
Relationships
SLA
Maintenance
Tasks
Comments
Attachments
Audits
History
5. When all selections/entries are made, click Save.
