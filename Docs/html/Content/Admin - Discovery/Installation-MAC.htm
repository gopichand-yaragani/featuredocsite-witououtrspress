Installing and Running the MAC Application

This function is not operational.

The Mac application can perform Unix System Discovery and Network Device Discovery in a Network.

Once the application is downloaded, follow the below installation steps.

1. Unzip the DiscoveryAgent_MAC.zip file.
2. On the terminal, run :sudo bash install.sh
3. Double-click virimamacagent.workflow.
4. In the Service Installer dialog box, click Install.
5. From the menu, select Finder > Services > virimamacagent.
