Uninstall the Discovery Application

The best and safest way to uninstall the existing application is by using a Windows uninstaller.

1. Go to Windows Control Panel and select Programs and Features.
2. Select Virima Discovery Application.
3. Click Uninstall.
4. Navigate to the installed location and delete the directory Virima Discovery Application to remove all the temp and log files.
