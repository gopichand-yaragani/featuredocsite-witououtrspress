## Personalize Columns

 -------------------------------------------------------------------------------------------------------------------------------------------- ------------------------------------------------------------------------------
 ![icon personalize list columns](../Resources/Images/Common Topics/icon-personalize-list-columns.png) Use this function to personalize the columns displayed in the record window.
 -------------------------------------------------------------------------------------------------------------------------------------------- ------------------------------------------------------------------------------

 -- ----- ----------------------------------------------------------------------
 1. While viewing a record list, click the **Personalize Columns** icon.
 -- ----- ----------------------------------------------------------------------

::: Ind50
[]{.image .placeholder original-image-src="../Resources/Images/Discovery/personalize-list-columns_332x238.png" original-image-title=""

::: Ind50
[]{.image .placeholder original-image-src="../Resources/Images/Discovery/personalize-columns_331x314.png" original-image-title=""

 -- ----- ----------------------------------------------------------------------------------------------------------------------
 2. In the *Search for properties* field, type the name of any properties to search for, then click the **Search** icon.
 -- ----- ----------------------------------------------------------------------------------------------------------------------

 -- ----- -----------------------------------------------------------------------
 3. In the *Search* field, type the name of any properties to search for.
 -- ----- -----------------------------------------------------------------------

 -- ----- -----------------------------------------------------------------------------------------------------------------------------------
 4. Under the *Search Results* column, a list of all available columns is shown. A check mark indicates the column has been selected.
 -- ----- -----------------------------------------------------------------------------------------------------------------------------------

 -- ----- -------------------------------------------------------------------------------------------------------------------------------------
 5. Under the *AVAILABLE FIELDS* column, a list of all available columns is shown. A check mark indicates the column has been selected.
 -- ----- -------------------------------------------------------------------------------------------------------------------------------------

 --- --------------------------------------------------------------------------------------------------------------
   The list of available columns are predefined in the system and cannot be changed through the user interface.
 --- --------------------------------------------------------------------------------------------------------------

 -- ----- --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
 6. Under the *SELECTED ITEMS* column, a list of all currently selected columns is shown. To add an item to this list, click on the column name in the *Search Results* list. The selected item is now available in the *Selected Items* list.
 -- ----- --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

 -- ----- --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
 7. Under the *SELECTED FIELDS* column, a list of all currently selected columns is shown. To add an item to this list, check the box for the field name in the *Available Fields* list. The selected item is now available in the *Selected Fields* list.
 -- ----- --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

 -- ----- ------------------------------------------------------
 8. Click **Default View** to load the default settings.
 -- ----- ------------------------------------------------------

 -- ----- ------------------------------------------------------------------------------
 9. Click **Clear All** to remove all selections and return to the default view.
 -- ----- ------------------------------------------------------------------------------

 -- ------ --------------------------------------------------
 10. Click **Save** to retain the current selections.
 -- ------ --------------------------------------------------

 -- ------ ------------------------------------------
 11. Click **Cancel** to discard any changes.
 -- ------ ------------------------------------------
