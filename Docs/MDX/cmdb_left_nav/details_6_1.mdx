# Details

- The [Details tab]{.Strong} provides the [primary information]{.Strong} for a Configuration Item (CI) and is the first section you see upon opening a CI record in the CMDB.

- It serves as the [core identity and profile view]{.Strong} of the asset, containing all critical fields related to the asset\'s configuration, lifecycle, and management metadata.

- The [Details view]{.Strong} consists of the following categories of data:

 - Asset primary information

 - Hardware and network

 - Operating system details

 - Supporting CIs

 - Contacts

 - Contracts
