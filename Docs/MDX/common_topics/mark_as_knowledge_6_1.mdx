## Mark as Knowledge

When selected, a confirmation message displays. Click **Yes** to create a knowledge item. A new window confirms and displays the Knowledge item number. Only one Knowledge item can be create for a CI. [LINK TO KNOWLEDGE MANAGEMENT]{style="color: #dc143c;"}.
